# План реализации Мини-PDM

> Для исполнителя: выполнять пункты последовательно в текущем сеансе, проверять каждый срез тестами и завершить полной сборкой и тестами.

**Цель:** работающее десктопное Mini-PDM по приложенному PDF.

**Архитектура:** Domain + Application + Infrastructure + Desktop. CAD-адаптер и SQLite отделены интерфейсами от сценариев. Дерево читается одним рекурсивным CTE.

**Стек:** .NET 8, Avalonia 11, SQLite, Dapper, xUnit.

**Спецификация:** `docs/superpowers/specs/2026-09-30-mini-pdm-design.md`.

## Общие ограничения

- Все комментарии, пользовательские тексты, документация и сообщения коммитов — на русском.
- Импорт принятой части папки атомарен; ошибочные файлы не прерывают пакет.
- Масса рассчитывается через `decimal`; связь состава ссылается на объект.
- `dotnet build` и `dotnet test` выполняются из корня.

## Проверки повышенного риска

- Самоссылка и многовершинный цикл отклоняют участников и предков.
- Ошибка JSON не прерывает чтение остальных файлов.
- Отмена текущей версии выбирает последнюю неаннулированную либо `null`.
- Повторный импорт меняет только два объекта v2 при предварительном утверждении.
- Повреждённые ссылки и переполнение произведения количеств не дают неверную массу.
