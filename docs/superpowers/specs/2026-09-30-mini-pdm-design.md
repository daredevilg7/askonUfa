# Проектирование Мини-PDM

## Цель и границы

Десктопная система импортирует два приложенных набора CAD-эмулятора, сохраняет объекты, версии и состав, показывает карточки, поиск, дерево, массу, сводную спецификацию и отчёт. Источником требований является PDF. Опросник `Тест.doc` не относится к программе.

## Архитектура

Четыре проекта: Domain (правила обозначений, состояний и расчётов), Application (сценарии импорта и интерфейсы доступа), Infrastructure (JSON, SQLite и рекурсивный SQL), Desktop (Avalonia MVVM). Направление зависимостей: Desktop → Application/Infrastructure, Infrastructure → Application/Domain, Application → Domain. Единственная композиция зависимостей находится в `App.axaml.cs`.

SQLite выбран как разрешённая PDF реляционная СУБД с рекурсивным CTE. Он даёт воспроизводимую демонстрацию без сервера БД. Массы хранятся текстом в инвариантной десятичной записи и вычисляются типом `decimal`; это исключает округление SQLite `REAL`.

## Данные и импорт

Адаптер читает все `.a3d`/`.m3d`; имя файла на диске является идентификатором. Ошибка JSON возвращается отдельной строкой, импорт других файлов продолжается. Прикладной сервис проверяет тип, обозначение, атрибуты, количество, уникальность в пакете, пропущенные ссылки, циклы и зависимых предков до открытия транзакции. Дубли обозначения или имени стандартного изделия отклоняются все. Повторяющиеся строки одного компонента суммируются с проверкой переполнения. Отсутствие массы детали — предупреждение, объект сохраняется.

Принятая часть набора записывается одной транзакцией. Для существующего объекта сравниваются нормализованные данные текущей версии и связи по идентификаторам дочерних объектов. Без изменения версия не трогается; текущая «В работе» обновляется; после «Утверждено» создаётся новая версия. Если текущей версии нет, создаётся версия с номером `max + 1`. Наименование — метаданные объекта, изменение только имени не создаёт версию. Дочерние связи указывают на объект, при расчёте берётся его текущая версия.

## Чтение и интерфейс

Один рекурсивный CTE возвращает выбранное дерево и произведения количеств по путям. Запрос защищён от циклов в повреждённой базе. При отсутствии текущей версии дочерний объект не участвует в расчётах. Масса не выдаётся, если хотя бы у одного листа она отсутствует; спецификация сохраняет строку с пустой массой. Поиск, выбор объекта, смена состояния, импорт папки и расчёты вызываются командами ViewModel. Code-behind инициализирует только представление.

## Проверка

Тесты проверяют валидацию, граф, повторный импорт через подменный CAD-reader, состояния, массу, спецификацию и реальную SQLite-транзакцию. Демонстрационный сценарий: базовый импорт (34 успеха, 1 предупреждение, 10 ошибок), утверждение версий, импорт v2, две новые версии и изменение массы корня с 98.8040 до 98.8800 кг.
