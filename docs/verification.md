# Повторная проверка по исходному заданию

Источник: все шесть страниц документа «Тестовое задание .NET: Мини-PDM „Состав изделия“». Требования сверены с кодом и проверками. Дополнительная часть не включена в критерии обязательной готовности.

## Обязательные требования

| Требование PDF | Подтверждение |
| --- | --- |
| .NET 8 или новее, WPF/Avalonia, реляционная СУБД | Проекты `net8.0`, Avalonia, SQLite; все проекты собираются |
| Абстракция CAD, отсутствие JSON и чтения CAD-файлов в остальной логике | `ICadDocumentReader` в Application, JSON-адаптер в Infrastructure; обоснование сигнатуры в README |
| Схема в репозитории | Встроенный `001_initial.sql`; интеграционный тест создания и повторного применения без потери данных |
| Дерево одним рекурсивным запросом | `GetTreeAsync` делает один `QueryAsync` с `TreeSql.Query`, содержащим `WITH RECURSIVE`; интеграционный тест вложенного дерева |
| Импорт в транзакции | `ApplyAsync`: одна транзакция для всех принятых документов; проверен откат всего набора при ошибке записи |
| Три типа объектов и обязательные атрибуты | 12 проверок неверных атрибутов; деталь без массы отдельно принимается с предупреждением |
| Строгое обозначение | Проверены кириллица, заглавные буквы, длины числовых групп, `Ё`, пустое значение, пробелы и перевод строки |
| Уникальное обозначение и имя стандартного изделия | Проверено отклонение всех совпадающих документов, в БД есть уникальные индексы |
| Неположительное количество, отсутствующий/отклонённый компонент | Проверены ноль, отрицательное количество и распространение ошибки на предков независимо от порядка входа |
| Повреждённый файл не прерывает импорт остальных | Подменный reader с ошибкой чтения; отдельные интеграционные проверки JSON и UTF-8 |
| Отчёт по каждому файлу и три счётчика | Проверены порядок/полнота строк, принятые, предупреждения и ошибки; предупреждения входят в число импортированных |
| Масса с вложенностью и количествами | Настоящий CTE возвращает количества 1, 8 и 15 для одной детали на разных уровнях; итог с двумя болтами — 3,1 кг |
| Сводная спецификация | Та же деталь агрегируется в 24 шт.; стандартное изделие без обозначения сохраняется отдельной строкой |
| Отсутствующая масса | Итог массы недоступен, проблемный компонент назван; строка спецификации остаётся с `null` массой |
| Циклы состава | Самоссылка, цикл из двух и трёх сборок, отклонение предков; защита расчётов от цикла после восстановления старой версии |
| Переходы состояний | Все девять сочетаний состояний в Domain; шесть запрещённых переходов дополнительно проверены через хранилище без изменения данных |
| Текущая версия и аннулирование | Проверены восстановление предыдущей версии, отсутствие текущей после отмены всех, следующий номер при новом импорте и исключение отменённого дочернего объекта из расчётов |
| Повторный импорт | Без изменений — нет новой версии; «В работе» обновляется; «Утверждено» получает новую версию; порядок состава не влияет на сравнение |
| MVVM и композиция | В `MainWindow.axaml.cs` только загрузка XAML; зависимости ViewModel передаются конструктором, композиция находится в `App.axaml.cs` |
| Дерево, карточка, смена состояния, поиск, импорт, масса и спецификация в UI | Проверены привязки и команды; кадры реального XAML на базовом наборе приведены в README |
| Поиск по обозначению и наименованию | Четыре интеграционные проверки, включая регистр кириллицы, стандартное изделие и отсутствие результата |
| Тесты импорта с подменой CAD-reader | Прикладные тесты используют `FakeReader` и не читают CAD-файлы; доступ к реальным файлам вынесен в отдельные интеграционные тесты адаптера |
| README и воспроизводимый запуск | Указаны команды, настройка пути SQLite, схема, архитектура, решения неоднозначностей, ограничения и оба отчёта данных |

## Приложенные наборы

- Базовый набор: 45 строк отчёта, 34 принятых без предупреждений, 1 предупреждение, 10 ошибок; сохранено 35 объектов. Тест проверяет точные имена всех ошибочных файлов и файла с предупреждением.
- Редуктор: 98,8040 кг, 25 листовых позиций, 118 изделий; регулировочных прокладок — 12.
- После утверждения исходных версий и импорта v2: 2 новые версии, 0 обновлений старых версий, 33 документа без изменений.
- Версия № 2 «В работе» появилась только у зубчатого колеса и крышки подшипника в сборе. Для всех 35 объектов проверены номера и состояния версий; версии № 1 остались утверждёнными.
- Старая масса колеса — 5,86 кг, старое количество прокладок в крышке — 3; они отдельно проверены в сохранённых версиях № 1.
- Корневая сборка осталась на версии № 1. Новая масса — 98,8800 кг, суммарное количество — 122, регулировочных прокладок — 16.

## Исправление, найденное при повторной проверке

Обозначение с завершающим переводом строки ошибочно считалось допустимым. Добавленный тест сначала воспроизвёл ошибку; после замены границ регулярного выражения на `\A` и `\z` он проходит. Остальные новые приёмочные тесты проверяют уже реализованные правила.

## Итог и границы проверки

Автоматический набор: **75 тестов**, без пропусков. Команды для воспроизведения из корня репозитория:

```bash
dotnet restore
dotnet build
dotnet test
```

На проверяющей машине используется .NET SDK 8.0.425. Приложение проверено запуском на macOS и рендерингом Avalonia в режиме Headless. Системный диалог выбора папки не проверялся автоматически; отдельные ручные прогоны на Windows и Linux не выполнялись.

Индикатор прогресса и отмена импорта, ленивая подгрузка, два провайдера БД, экспорт, сравнение версий и структурированное логирование относятся к дополнительной части и не реализованы. Импорт выполняется в фоне; для SQLite не требуется Docker или внешняя СУБД.
